# DeepOS — Visione

## L'idea

Un sistema operativo cognitivo che vive sul telefono e cresce con chi lo usa.

Non è un chatbot. Non è un antivirus. È un **cervello personale** con:

- memoria persistente
- policy che decide cosa può fare
- esecutore controllato
- audit di ogni azione
- sensore sul device che osserva e correla
- valutatore che evita di risolvere il problema sbagliato

## Principio non negoziabile

> TAUROS diventa più potente soltanto quando diventa anche più controllabile.

Niente god mode. Niente azioni invisibili. Ogni osservazione è spiegabile, verificabile, cancellabile.

## Direzione

1. **v1** — Core cognitivo funzionante + PWA + Problem Agent + Sentinel MVP
2. **v2** — App mobile unificata, voce, multi-canale (Telegram)
3. **v3** — Plugin firmati, automazioni controllate, APK nativo
4. **v4** — Sync multi-dispositivo, memoria distribuita
